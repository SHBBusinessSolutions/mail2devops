Mail2DevOps

E-Mails als Diskussion an Azure DevOps Work Items anhängen

1. Manifest herunterladen

⬇ Manifest herunterladen

Bitte diesen Button verwenden. Wird die Datei im Browser geöffnet und über „Speichern unter“ gespeichert, ist sie für Outlook unbrauchbar.

2. In Outlook hinzufügen

  1. aka.ms/olksideload öffnen (Outlook im Web).
  2. Meine Add-Ins → ganz unten Benutzerdefinierte Add-Ins → Benutzerdefiniertes Add-In hinzufügen → Aus Datei hinzufügen.
  3. Die heruntergeladene Mail2DevOps-manifest.xml wählen und bestätigen.
  4. Eine E-Mail öffnen → An DevOps senden (ggf. unter Apps). Im neuen und klassischen Outlook erscheint es ebenfalls.

3. Einrichten

Beim ersten Öffnen über das Zahnrad ⚙ die Azure DevOps Organisation und einen persönlichen Zugriffstoken (PAT) eintragen. Benötigte Rechte: Work Items (Read & Write) und Project and Team (Read).
